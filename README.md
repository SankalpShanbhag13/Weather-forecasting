# Weather App

A simple weather forecasting application with a web-based interface and Python backend integration.

## Features

- Real-time weather information display
- Clean and responsive user interface
- DateTime integration for accurate time tracking
- Easy-to-use design

## Project Structure

```
Weather app/
├── index.html      # Main HTML file with page structure
├── script.js       # JavaScript for frontend functionality
├── style.css       # CSS styling and layout
├── datetime.py     # Python backend for datetime operations
└── README.md       # Project documentation
```

## Files

### Frontend
- **index.html** - Main HTML page with the weather app interface
- **script.js** - Handles dynamic functionality and interactions
- **style.css** - Styles and responsive layout for the app

### Backend
- **datetime.py** - Python script for datetime-related operations

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/SankalpShanbhag13/Weather-forecasting.git
   cd Weather-forecasting
   ```

2. Open the application:
   - Open `index.html` in a web browser to access the weather app

3. For Python backend:
   - Ensure Python 3.x is installed
   - Run `datetime.py` if needed for backend operations

## Usage

1. Open `index.html` in your web browser
2. The app will display weather information and current date/time
3. Use the interface to interact with weather data

## Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Python

## Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Python 3.x (for backend operations)
